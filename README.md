# Muhammad Shakeel Portfolio

A static portfolio built with React, Vite, and Tailwind CSS. The contact form opens WhatsApp with a prefilled project inquiry for the visitor to review and send.

## Run locally

From the project directory, run:

```sh
npm ci
npm run dev
```

## Deploy

Run `npm run build` and publish the generated `dist/` directory. Configure your static host to serve `index.html` for client-side routes. The included Vercel configuration provides this rewrite.
